# Cross-species epilepsy: pathway transfer and functional organization

The notebook summarizes a strict study-unseen comparison of human mesial temporal lobe epilepsy and phase-specific mouse kainate epilepsy using frozen BridgeRNA representations. It executes entirely from compact cached aggregate evidence and does not require source expression matrices, model checkpoints, embeddings, or network edge arrays.

## Contents

- `cross_species_epilepsy.ipynb`: executed scientific report.
- `data/`: compact source tables, provenance, hashes, and tested Python dependencies.
- `figures/`: PNG/PDF figures used or regenerated by the notebook.

The research source of truth is `research/cross_species_mtle/`. The notebook generator is `research/cross_species_mtle/pipeline/build_publication_notebook.py`.

## Lightweight execution

From the repository root:

```bash
python -m pip install -r benchmarks/cross_species_epilepsy/data/requirements.txt
cd benchmarks/cross_species_mtle
jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.timeout=300 cross_species_epilepsy.ipynb
```

Execution is offline, uses less than 10 MB of packaged inputs/figures, and typically completes in under one minute on CPU.

To rebuild the cache and notebook from the frozen research benchmark:

```bash
python research/cross_species_mtle/pipeline/build_publication_notebook.py --execute
```

## Full benchmark workflow

The compact report does not rerun Bridge inference. Full reconstruction requires the datasets, checkpoint, and environments documented in `research/cross_species_mtle/README.md` and `research/cross_species_mtle/reports/FINAL_REPORT.md`. The main stages are:

```bash
# Construct validated Bridge inputs and manifests.
python research/cross_species_mtle/pipeline/prepare_primary_inputs.py --help

# Run frozen sample representations and matched Bridge/raw/PCA analysis.
python research/cross_species_mtle/pipeline/run_sample_level_benchmark.py --help

# Apply the frozen Hallmark head and compare with conventional GSEA.
python research/cross_species_mtle/pipeline/run_hallmark_head_validation.py --help
python research/cross_species_mtle/pipeline/run_hallmark_gsea_comparison.py --help
```

The full workflow requires access to the frozen Bridge checkpoint, validated human TPM and mouse count-derived TPM, and a GPU for inference. Contextual token extraction produces multi-gigabyte arrays and should use the monitoring/logging commands documented by the research benchmark. None of those expensive stages is required to execute this notebook.

## Interpretation boundary

The prespecified cross-species sample-direction endpoint did not exceed phenotype-label nulls. The strongest supported contribution is higher-order program organization: a frozen human GTEx-trained Hallmark head broadly recovered the mouse Hallmark landscape zero-shot and identified coherent phase-resolved injury, metabolic, and signaling programs. Because the head targets expression-derived pathway scores, agreement with GSEA is transfer/recovery evidence rather than an independent pathway assay.
