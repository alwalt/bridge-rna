# TCGA to ARCHS4 Hallmark-state retrieval

This package reports how a frozen GTEx-trained Bridge `512 → 50` Hallmark readout supports functional-state retrieval across 510,709 human ARCHS4 samples. It compares raw-cosine Hallmark retrieval with raw Bridge-512 retrieval and a scoped expression-space baseline.

## Lightweight execution

The notebook uses only the compact cached tables in `data/`; it does not load the Bridge checkpoint, embeddings, expression matrices, or full top-100 prediction tables.

```bash
python -m pip install -r notebooks/tcga_archs4_state_retrieval/data/requirements.txt
jupyter nbconvert \
  --to notebook \
  --execute notebooks/tcga_archs4_state_retrieval/tcga_archs4_state_retrieval.ipynb \
  --output tcga_archs4_state_retrieval.ipynb \
  --output-dir notebooks/tcga_archs4_state_retrieval \
  --ExecutePreprocessor.timeout=600
```

The executed report regenerates PNG and PDF figures beneath `figures/` and checks the cached cohort sizes, table shapes, and headline values.

## Regenerate notebook source

```bash
python benchmarks/tcga_archs4_state_retrieval/pipeline/make_notebook.py
```

## Full benchmark

The research pipeline remains the source of truth:

```bash
bash benchmarks/tcga_archs4_state_retrieval/pipeline/run_all.sh
```

The full run requires the authoritative Bridge checkpoint and configuration, canonical 15,165-gene vocabulary, TCGA expression and embeddings, the 510,709-sample ARCHS4 embedding store and metadata, the frozen GTEx Hallmark head, GPU access for exact full-corpus retrieval, and substantial local storage. Monitor it with:

```bash
tail -f benchmarks/tcga_archs4_state_retrieval/results/run.log
```

The full pipeline was not rerun during packaging.

## Contents

- `tcga_archs4_state_retrieval.ipynb` — executed scientific report.
- `data/` — compact cached numerical evidence copied without modification from the benchmark results.
- `figures/` — figures regenerated by the notebook as PNG and PDF.
- `data/package_provenance.json` — source revision, frozen-model hashes, cached-artifact hashes, scope, and validation record.
- `benchmarks/tcga_archs4_state_retrieval/pipeline/make_notebook.py` — deterministic notebook source generator.
- `data/requirements.txt` — minimal report dependencies.

The 50 outputs are continuous predictions of GTEx-standardized rank-mean Hallmark targets. They are not probabilities, GSEA enrichment scores, formal ssGSEA scores, or outputs of the contextual gene-level decoder.
